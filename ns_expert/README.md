# NEXS — Neuro-symbolic EXpert System

Reproducible code for the study *"A Neuro-Symbolic Expert System that Learns the
Rules"*. NEXS couples a **differentiable rule layer** (per-rule confidences
anchored to an expert's certainty factors) with a neural tabular head, and is
compared against a classical certainty-factor expert system, classical learners,
an MLP, and a semantic-loss neuro-symbolic model.

The two benchmarks are synthetic by design: data are generated by a **known Horn
rule base with hidden intermediate concepts**, so we can measure not only
accuracy but whether each model *recovers the underlying logic*.

## Layout

```
src/
  knowledge.py       domains, ground-truth rules, imperfect "expert" rules
  data.py            regime-mixture data generator with hidden concepts
  real_data.py       real datasets (heart, pima, tic-tac-toe) + clinical KBs
  expert_system.py   forward chaining + MYCIN certainty factors
  models.py          MLP, SemanticLoss, NEXS (differentiable rule layer)
  baselines.py       logistic regression, decision tree, RF, gradient boosting
  rules.py           deterministic oracle, rule extraction, recovery metrics
experiments/
  run_experiments.py      runs synthetic E1..E7 -> results/*.csv
  run_real_experiments.py runs real-data E1..E7 -> results/real_*.csv
  make_figures.py         synthetic figures/tables
  make_real_figures.py    real-data figures/tables
paper/               LaTeX manuscript + references.bib
data/                small real datasets (fetched, committed)
```

## Real datasets

Three small, standard datasets are used (`src/real_data.py`):

| Dataset | Rows | Task | Knowledge source |
|---------|------|------|------------------|
| `heart` | 303 | UCI Cleveland heart disease | clinical guideline cut-offs (approx.) |
| `pima`  | 768 | Pima Indians diabetes | ADA/WHO cut-offs (approx.) |
| `ttt`   | 958 | tic-tac-toe endgame | **genuine** logic: 8 winning lines |

On `heart`/`pima` there is no ground-truth rule base, so rule recovery is
measured against the *expert KB* and logic fidelity against the *KB oracle* — how
much of the expert's logic the learned model preserves. On `ttt` the eight
winning lines are a real ground truth, so rule recovery is measured against the
true logic, bridging the synthetic and real studies.

Data are fetched from UCI / public mirrors into `data/` and committed, so runs
are offline-reproducible.

All learned models use balanced class weighting (applied uniformly) to match the
class imbalance of these datasets. Accuracy is reported at the F1-optimal
validation threshold; `acc*` is at the accuracy-optimal threshold, which can
differ by several points on imbalanced data. Headline real-data results (mean over
5 seeds, `results/real_e1_main.csv`):

| Dataset | ESS acc | Best learned acc | NEXS acc (acc*) | NEXS AUC | NEXS logic fid. | ESS rule F1 |
|---------|---------|------------------|-----------------|----------|-----------------|-------------|
| heart | 0.751 | **0.836 (NEXS)** | 0.836 (0.833) | 0.902 | 0.748 | 1.000 |
| pima  | 0.756 | 0.723 (RF) | 0.696 (0.740) | **0.836** | 0.640 | 1.000 |
| ttt   | 1.000 | 0.997 (NEXS) | 0.997 (0.997) | **1.000** | **0.992** | 1.000 |

The pattern: where the KB is exact (ttt) the expert system is perfect and
recovers the true logic exactly, while learned models match its accuracy but not
its rules; where the KB is approximate (heart, pima) the expert system is
beatable and NEXS is the most accurate model on heart and has the best AUC on
pima and ttt, while retaining the most expert logic of any learned model.

## Method (NEXS)

```
z(x) = f(x) + alpha * logit( p_sat(x) )
L    = BCE(sigmoid(z), y) + lambda_sem * BCE(p_sat, y)
       + lambda_prior * mean_r (c_r - c*_r)^2
```

`p_sat` is the probabilistic sum of the rule bodies (product t-norm for
conjunction); `c_r` are learnable rule confidences initialised from the expert
certainty factors `c*_r`. Setting `alpha=0` removes the rule layer,
`lambda_sem=0` removes the semantic term, `lambda_prior=0` removes the expert
anchor, and `alpha_only=True` yields the rule-layer-only ablation.
